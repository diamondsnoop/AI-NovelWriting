# V0.3.0验收文档

## 验收目标

本次验收用于确认 `V0.3.0` 是否达到“内容质量稳定版”的收尾标准。

验收标准如下：

1. 连续写 `5` 章
2. `character checker` 拦截不超过 `1` 次，且拦截原因经人工确认是真实问题
3. `structured_summary` 的 `key_events` 和 `main_plot_advanced` 字段稳定输出，不出现静默空值
4. `foreshadowing` 每章条目数量在 `5` 条以内，不出现明显近重复
5. 主链路不因这轮改动而回退

## 验收过程

在全新项目 `acceptance_v03` 上运行真实 API 主链路：

1. `init`
2. `plan chapter 1` 到 `plan chapter 5`
3. `write chapter 1` 到 `write chapter 5`

验收过程中不复用 `demo_real` 的历史数据，避免旧项目中的遗留实体、伏笔和章节回写影响判断。

## 已知但不阻塞关版的问题

以下问题在本次验收中出现，但不构成 `V0.3.0` 的阻塞项：

1. 写作正文偶尔会出现命名质量问题
例如主角名、配角名的选择还不够稳定，属于写作 prompt 约束问题。

2. 正文中偶尔会出现章节标题风格漂移
这属于 `writer_engine` 的生成约束问题，不是状态层、检索层或审查层回退。

3. 个别章节仍存在连续性提示
这些是内容质量层面的正常反馈，不代表系统链路失效。
